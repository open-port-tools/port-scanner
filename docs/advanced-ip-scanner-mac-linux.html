Advanced IP Scanner for Mac & Linux

Advanced IP Scanner is one of the most widely used network utilities in Windows environments. Because Famatech has never built a native macOS or Linux version, Open Port Scanner serves as the direct cross-platform solution.

Can You Run Advanced IP Scanner on macOS or Linux?

Not natively. The official Advanced IP Scanner installer only runs on Windows (x86/x64). Common workarounds include:

  • Running via Wine / CrossOver: Network layer discovery and ARP table inspection frequently fail or freeze inside compatibility layers.
  • Virtual machines (Parallels / VMware): Spinning up a Windows virtual machine simply to find a local IP address consumes 4+ GB of RAM and considerable setup time.

How to Discover Connected Network Devices on Mac & Linux

Option 1: Graphical Desktop Interface

Launch port-scanner by double-clicking the binary or running it from Terminal. The app automatically populates your active local subnet (e.g. 192.168.1.0/24). Select the LAN button and click Scan. Active devices, open ports, and server titles appear in real time.

Option 2: Terminal Command

If you are working over an SSH connection or prefer the command line: 

# Scan your local LAN with the quick preset:
./port-scanner --lan --profile quick

# Save output to JSON for documentation or reporting:
./port-scanner --lan -o network-inventory.json
