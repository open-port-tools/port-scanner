When auditing a server or scanning a local subnet, recognizing port numbers quickly helps distinguish expected services from misconfigured databases or exposed admin panels.

Core infrastructure and remote access ports

Port Service Description & Security Note
21 FTP File Transfer Protocol. Unencrypted; replace with SFTP (port 22) where possible.
22 SSH / SFTP Secure Shell. Use key-based auth and disable root password login.
23 Telnet Unencrypted remote terminal. Often found on legacy switches or IoT devices; disable if unused.
25 / 465 / 587 SMTP Mail transfer and submission.
53 DNS Domain Name System (TCP used for zone transfers and large responses).
445 SMB Windows file sharing. Keep restricted to internal trusted subnets only.
3389 RDP Remote Desktop Protocol. Never expose directly to the public Internet without VPN/NLA.
5900 VNC Graphical remote desktop. Tunnel over SSH or VPN rather than exposing raw port 5900.

Web servers and local development ports

Port Service Typical Usage
80 HTTP Unencrypted web traffic and router configuration portals.
443 HTTPS TLS-encrypted web traffic and APIs.
3000 Dev Server Default port for Node.js, React, Grafana, and Ruby on Rails.
5173 Vite Default frontend dev server port for Vite applications.
8000 / 8080 HTTP-Alt Python, Django, Tomcat, Jenkins, and reverse proxy backends.
8443 HTTPS-Alt Management interfaces (UniFi, Proxmox, Synology DSM, admin panels).
9000 / 9090 Admin / Metrics Portainer, MinIO, SonarQube, Prometheus, and Cockpit.

Database and cache ports

Port Database Audit Checklist
1433 Microsoft SQL Server Bind to private interface; avoid exposing on public IP.
3306 MySQL / MariaDB Restrict remote host grants and enforce TLS for non-local connections.
5432 PostgreSQL Verify pg_hba.conf rules if reachable across LAN.
6379 Redis Default config often lacks authentication; bind to 127.0.0.1 or enable ACLs.
9200 Elasticsearch REST API port; ensure security plugin and TLS are active.
27017 MongoDB Ensure authorization is enabled before binding to 0.0.0.0.
