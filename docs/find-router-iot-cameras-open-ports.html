How to audit routers, IP cameras, and IoT devices for open ports

Consumer routers, security cameras, and smart home hubs often ship with legacy diagnostic ports enabled by default. Running a periodic subnet scan lets you spot exposed services before they become a liability.

Common open ports on IoT and network hardware

Port Service / Purpose Recommended Action
23 Telnet High risk. Disable Telnet in device firmware settings; credentials are sent in plaintext.
80 / 8080 HTTP Admin Panel Change default passwords and ensure UPnP / remote WAN management is disabled.
554 RTSP (Video Stream) Used by IP cameras (Hikvision, Dahua, Reolink). Require authentication and isolate on a separate VLAN.
1883 / 8883 MQTT Smart home message brokers (Home Assistant / Tasmota). Enforce username/password auth.
7547 TR-069 ISP remote router management port. Should never be accessible from the public WAN.

Running an IoT port audit

# Scan your entire local subnet across standard + IoT ports:
port-scanner --lan -p 21,22,23,80,443,554,1883,5000,7547,8000,8080,8443

# Deep audit of your main router (e.g. 192.168.1.1):
port-scanner 192.168.1.1 --profile common
