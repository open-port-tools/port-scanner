Сканер открытых портов и локальной сети (LAN)

Сверхбыстрый, нативный сканер TCP-портов на Rust с определением всей сети в 1 клик. Сканируйте локальный ПК или все 254 хоста домашней/офисной подсети за секунды в тёмном интерфейсе без установки Java и драйверов.

Скачать для Windows (.exe · 2.1 МБ) Скачать для macOS (Universal · 4.4 МБ) Скачать для Linux (x64 · 2.8 МБ) Исходный код на GitHub ⭐

Почему системные администраторы и разработчики выбирают его

⚡ Асинхронный движок на Rust

На базе Tokio. Сканирует сотни хостов и тысячи портов параллельно без утечки сокетов и зависания системы.

🌐 1 Клик — вся сеть (LAN /24)

Автоматически определяет активную подсеть Wi-Fi или Ethernet, фильтруя loopback и фейковые VPN-пулы (198.18.0.0/15).

🖥️ Ноль зависимостей (Без Java и Npcap)

Работает сразу из коробки на Windows (.exe), macOS и Linux. Не требует установки JRE, Python или системных драйверов захвата пакетов.

🔍 Баннеры и заголовки HTTP

Считывает приветствия SSH, HTTP-статусы, заголовки Server и title веб-страниц с замером точного пинга в миллисекундах.

📊 Экспорт в CSV и JSON

Сохранение отчётов в 1 клик в Загрузки или Рабочий стол с автоматическим копированием в буфер обмена для документации.

🪶 Размер бинарника ~2–4 МБ

Один компактный файл. Можно носить на флешке или запускать на удалённых серверах без пакетных менеджеров.

Быстрая установка и консольное использование

# Установка через Cargo (crates.io):
cargo install open-port-scanner

# Сканирование всей локальной сети за 2 секунды:
port-scanner --lan --profile quick

# Проверка конкретных портов с экспортом в JSON:
port-scanner 192.168.1.0/24 -p 22,80,443,3389 -o report.json

# Запуск графического интерфейса:
port-scanner --gui
