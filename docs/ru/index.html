Сканер открытых портов и локальной сети (LAN)

Нативный сканер TCP-портов на Rust с определением всей подсети в один клик. Проверяет локальный ПК или все 254 хоста домашней или офисной сети за секунды из графического интерфейса или терминала, без установки Java и драйверов.

Скачать для Windows (.exe, 2.1 МБ) Скачать для macOS (Universal, 4.4 МБ) Скачать для Linux (x64, 2.8 МБ) Исходный код на GitHub

Основные возможности

Асинхронный движок на Rust

Построен на Tokio. Сканирует сотни хостов и тысячи портов параллельно без перегрузки системы.

Определение всей сети (LAN /24)

Автоматически находит активную подсеть Wi-Fi или Ethernet, фильтруя loopback и виртуальные VPN-туннели (198.18.0.0/15).

Без Java и драйверов Npcap

Работает сразу на Windows (.exe), macOS и Linux. Не требует JRE, Python или драйверов захвата пакетов.

Баннеры и заголовки HTTP

Считывает приветствия SSH, HTTP-статусы, заголовки Server и title веб-страниц с замером пинга в миллисекундах.

Экспорт в CSV и JSON

Сохранение отчётов в Загрузки или Рабочий стол с копированием в буфер обмена для документации.

Размер бинарника 2-4 МБ

Один автономный файл. Можно носить на флешке или запускать на серверах без пакетных менеджеров.

Быстрая установка и консольное использование

# Установка через Cargo (crates.io):
cargo install open-port-scanner

# Сканирование всей локальной сети за 2 секунды:
port-scanner --lan --profile quick

# Проверка конкретных портов с экспортом в JSON:
port-scanner 192.168.1.0/24 -p 22,80,443,3389 -o report.json

# Запуск графического интерфейса:
port-scanner --gui
