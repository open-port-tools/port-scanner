Is There an Official Advanced Port Scanner for Mac or Linux?

No. Famatech has never released a macOS or Linux edition of Advanced Port Scanner. System administrators working in mixed OS environments often struggle to find a tool that offers the same simplicity:

  • Nmap / Zenmap: Powerful, but requires root privileges, driver installation (Npcap), and complex command-line syntax.
  • Angry IP Scanner: Works across platforms, but mandates installing a bloated Java runtime environment (JRE).
  • Wine / Emulation: Running Windows port scanners via Wine often fails because low-level socket operations behave differently in emulated environments.

Why Open Port Scanner is the Best Alternative

Open Port Scanner v2.0 solves this gap by compiling directly to native machine code on macOS, Linux, and Windows:

How to Scan Your LAN on macOS & Linux

1. Desktop GUI Experience

Download the standalone release for your operating system, double-click to launch, and click the «Вся сеть» button. The tool immediately probes your entire local subnet for active web servers, SSH daemons, databases, and network equipment.

2. Command-Line Experience

For automation, system monitoring, or SSH sessions, run Open Port Scanner directly from the terminal: 

# 1-Click LAN scan:
./port-scanner --lan --profile quick

# Full sweep of specific host with CSV export:
./port-scanner 192.168.0.1 --profile full -o gateway-ports.csv
