Advanced Port Scanner for macOS and Linux

Famatech's Advanced Port Scanner is limited to Microsoft Windows. For users on macOS or Linux who need a subnet scanner with a desktop interface, Open Port Scanner provides a native cross-platform alternative.

Is There an Official Advanced Port Scanner for Mac or Linux?

No. Famatech has never released a macOS or Linux edition of Advanced Port Scanner. Common workarounds on non-Windows systems each carry trade-offs:

  • Nmap / Zenmap: Capable, but requires root privileges, packet capture drivers, and detailed syntax knowledge for basic sweeps.
  • Angry IP Scanner: Cross-platform, but requires an external Java runtime (JRE) installation.
  • Wine / Emulation: Running Windows network utilities via Wine often produces incomplete results because low-level socket APIs behave differently in emulation.

How to Scan Your LAN on macOS and Linux

1. Desktop GUI

Download the standalone release for macOS or Linux, run the binary, and select the LAN subnet target (or run with --gui). The scanner probes your local subnet for active web servers, SSH daemons, databases, and network hardware.

2. Command-Line Interface

For automation, headless servers, or quick terminal checks: 

# Scan your active local subnet:
./port-scanner --lan --profile quick

# Scan a gateway host and save results to CSV:
./port-scanner 192.168.0.1 --profile full -o gateway-ports.csv
